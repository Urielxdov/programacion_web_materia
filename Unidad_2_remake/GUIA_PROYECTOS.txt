COMO PREPARARLOS Y ENTRAR
-------------------------

0. Requisitos de la PC

  - Navegador: todos los proyectos.
  - PHP 8.1+ con pdo_mysql (XAMPP sirve): proyecto_individual y
    proyecto_final.
  - MySQL/MariaDB encendido: proyecto_individual y proyecto_final.
  - Python 3 o Docker Desktop, y PostgreSQL: equipo_4.

  Estado de esta PC al preparar la guia: PHP y Python no estan en el PATH,
  MySQL (3306) y PostgreSQL (5432) estan escuchando, y Docker Desktop esta
  instalado pero apagado. Instala o activa lo que falte segun el proyecto.

1. Solo abrir (sin instalar nada)

  practica_1/*.html, sitio_web_responsivo/index.html, equipo_3/index.html y
  equipo_6/index.html: doble clic o arrastrar al navegador.
  - equipo_6: pega tu API key de Google Gemini arriba y pulsa "Conectar al
    Servidor".

2. Menu con frames + CRUD de citas

  cd Unidad_2_remake
  php -S localhost:8080

  Abre http://localhost:8080/PresentacionActividades.html (o directo
  http://localhost:8080/proyecto_individual/index.php).

  Base de datos, una sola vez:
  1. Enciende MySQL.
  2. Ejecuta proyecto_individual/schema.sql (phpMyAdmin o
     "mysql < schema.sql"). Crea sistema_citas con las tablas usuarios y
     citas.
  3. Puerto: conexion.php usa el 3307 por defecto. Si tu MySQL esta en 3306,
     arranca asi (PowerShell):

       $env:CITAS_DB_PORT="3306"; php -S localhost:8080

     Tambien existen CITAS_DB_HOST, CITAS_DB_USER y CITAS_DB_PASS.
  4. En el login, registrate primero: ese usuario sera admin.

3. proyecto_final (E-Waste 360)

  cd Unidad_2_remake\proyecto_final
  copy .env.example .env                  (ya esta creado en esta PC)
  $env:SEED_PASSWORD="Demo2026x"          (minimo 8 caracteres, letras y numeros)
  php database/instalar.php --crear-bd    (solo la primera vez)
  php -S localhost:8000 -t public public/router.php

  Entra a http://localhost:8000 con admin, responsable o capturista y la
  contrasena de SEED_PASSWORD.
  - .env apunta a MySQL en 127.0.0.1:3306, usuario root sin contrasena;
    ajustalo si tu MySQL es distinto.
  - Para PostgreSQL, descomenta DATABASE_URL en .env y habilita pdo_pgsql.
  - Reiniciar datos: php database/instalar.php --reiniciar
  - Documentacion: proyecto_final/docs/ (arquitectura, API, manual de
    usuario, diagramas en diagramas.html).

4. equipo_4 (API de tareas)

  Opcion A - Docker (recomendada)

    cd Unidad_2_remake\equipo_4
    copy .env.example .env      (edita DEMO_PASSWORD, DB_PASSWORD y SECRET_KEY)
    docker compose up --build   (abre Docker Desktop antes)

    Queda en http://localhost:8000 (PostgreSQL en el puerto 5433).

  Opcion B - Python local (requiere PostgreSQL)

    cd Unidad_2_remake\equipo_4
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    copy .env.example .env      (edita SECRET_KEY, DB_* y DEMO_PASSWORD)
    python manage.py migrate
    python manage.py crear_demo
    python manage.py runserver 8001

    Queda en http://127.0.0.1:8001, que es el enlace que usa el menu.

  Ojo: Docker publica el 8000, el mismo puerto que proyecto_final. No los
  corras a la vez, o usa la opcion B (8001). Con Docker, el enlace del menu
  (8001) no coincide.

  Detalles y despliegue (Render, Cloud Run): equipo_4/README.md y
  equipo_4/DEPLOY_GCP.md.


PROBLEMAS COMUNES
-----------------

- "php" no se reconoce
  PHP no esta en el PATH; agrega C:\xampp\php o instala PHP.

- "Error de conexion a la base de datos" en citas
  Puerto equivocado: usa CITAS_DB_PORT=3306 o enciende MySQL.

- Los enlaces de equipo_4 / proyecto final del menu no cargan
  Falta levantar su servidor (8001 / 8000).

- "docker compose" falla al conectar
  Docker Desktop esta apagado.

- El menu se ve vacio en el navegador
  Los frameset son HTML antiguo; abre indiceActividades.html directo si tu
  navegador los bloquea.
