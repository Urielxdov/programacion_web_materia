ARQUITECTURA WEB: LA ESTRUCTURA DE INTERNET

Cómo se organizan los sitios web y las tecnologías que los hacen posibles
La arquitectura web impulsa la comunicación digital

La arquitectura web es el conjunto de elementos, tecnologías y servicios que permiten crear, publicar y utilizar sitios y aplicaciones en Internet. Su objetivo principal es organizar correctamente la comunicación entre los usuarios, los servidores y las bases de datos.

Cuando una persona visita una página web, el navegador envía una solicitud a un servidor. Este procesa la petición, consulta la información necesaria y devuelve una respuesta que el navegador muestra en pantalla.

Una arquitectura bien diseñada permite que los sitios sean rápidos, seguros, accesibles y capaces de atender a muchos usuarios al mismo tiempo.

La arquitectura web como la arquitectura de un edificio, requiere planificación, diseño y mantenimiento para garantizar que funcione correctamente y cumpla con las necesidades de sus usuarios.
Componentes principales

Frontend: es la parte visible de un sitio web. Utiliza HTML para la estructura, CSS para el diseño y JavaScript para la interacción.

Backend: procesa la información del servidor, administra usuarios y ejecuta la lógica de la aplicación.

Base de datos: almacena información como usuarios, productos, publicaciones y configuraciones.

Servidor: recibe solicitudes y entrega los recursos necesarios para que la página funcione.

Protocolo HTTP: es el lenguaje que permite la comunicación entre el navegador y el servidor.

Protocolo HTTPS: es una versión segura del protocolo HTTP que utiliza cifrado para proteger la información transmitida.

Protocolo FTP: es un protocolo utilizado para transferir archivos entre un cliente y un servidor.
