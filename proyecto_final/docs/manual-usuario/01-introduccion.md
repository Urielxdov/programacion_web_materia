# 1. Introducción

## 1.1. ¿Qué es E-Waste 360°?

E-Waste 360° es una plataforma web para gestionar equipos electrónicos fuera de uso en una institución educativa. Permite registrar su ingreso, evaluar su condición y documentar si se reparan, se reasignan, se conservan como respaldo o se entregan a un gestor verificado.

Cada equipo recibe un folio y conserva un historial de movimientos. La plataforma también permite organizar campañas de recolección, registrar participaciones y consultar indicadores ambientales, sociales y económicos. Su propósito es favorecer el aprovechamiento de los equipos y dar seguimiento a los residuos de aparatos eléctricos y electrónicos (RAEE).

## 1.2. A quién va dirigido

| Perfil | Uso principal |
|---|---|
| Visitante | Consultar información y campañas y registrar su intención de participar. |
| Capturista | Registrar equipos, consultar el inventario y corregir datos permitidos. |
| Responsable ambiental | Diagnosticar equipos, registrar reparaciones y destinos y gestionar campañas y reportes. |
| Administrador | Administrar cuentas, roles, categorías y verificaciones de gestores, además de las operaciones anteriores. |

No se requieren conocimientos de programación para utilizar este manual. Las cuentas del personal son proporcionadas por el administrador.

## 1.3. Cómo usar este manual

1. Revisa [Requisitos y acceso](02-requisitos-y-acceso.md).
2. Sigue [Primeros pasos](03-primeros-pasos.md) para conocer el menú y el inicio de sesión.
3. Consulta el apartado correspondiente a tu rol. El responsable y el administrador también pueden seguir los procedimientos del capturista.
4. Ante una dificultad, consulta [Preguntas frecuentes](09-preguntas-frecuentes.md).
5. Busca los términos desconocidos en el [Glosario](10-glosario.md).

Los nombres en **negritas** identifican botones, campos o secciones. La secuencia **Equipos → Ver → Editar datos** indica el orden de navegación. Los ejemplos son ilustrativos.

Comprueba los campos obligatorios antes de enviar un formulario y verifica el resultado guardado después de recibir la confirmación.
