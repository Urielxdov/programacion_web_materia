# 5. Capturista

[Volver a portada e índice](../manual-usuario.md)

**Requisito:** iniciar sesión como capturista, responsable ambiental o administrador.

## 5.1. Registrar un equipo

1. Selecciona **Registrar equipo**.
2. En el primer paso, elige el tipo de equipo y pulsa **Continuar**.
3. En el segundo paso, completa los datos:

   | Dato | Indicaciones |
   |---|---|
   | Marca | Obligatoria. Si no se conoce, indica “Sin marca”. |
   | Modelo | Obligatorio. Si no se conoce, indica “Desconocido”. |
   | Número de serie | Obligatorio para computadoras. Revisa la etiqueta del fabricante y evita duplicados. |
   | Fecha de ingreso | Obligatoria; no puede ser posterior al día actual. |
   | ¿Dónde está guardado? | Ubicación física para localizar el equipo. |
   | ¿Llegó en una campaña? | Selecciona el origen real cuando corresponda. Debe aceptar el tipo elegido. |
   | Observaciones | Información adicional, hasta 1000 caracteres. |

4. Pulsa **Continuar** y revisa el resumen del tercer paso.
5. Si hay errores, pulsa **Regresar** para corregirlos.
6. Pulsa **Guardar equipo** y espera la confirmación.
7. Consulta la ficha y anota el folio, por ejemplo `EW-2026-0047`. Puedes utilizarlo para identificar físicamente el aparato.

El equipo ingresa pendiente de diagnóstico. El formulario conserva un borrador en la pestaña actual para retomar una captura interrumpida. Se limpia al guardar y puede perderse al cerrar la pestaña; no equivale a un registro definitivo.

El selector de campaña excluye las campañas **Próximamente** y muestra las compatibles con el tipo de equipo, incluidas las concluidas. Selecciona siempre la que corresponda al ingreso real, incluso si estás documentando una recepción anterior.

## 5.2. Buscar y consultar equipos

1. Abre **Equipos**.
2. Busca por folio, marca, modelo, serie o ubicación.
3. Combina los filtros **Tipo de equipo**, **Condición**, **Destino** y **Campaña**.
4. Recorre el listado con la paginación.
5. Pulsa el folio, **Ver** o la tarjeta para abrir el equipo.

La ficha muestra tipo, serie, fecha de ingreso, ubicación, condición, campaña, persona que lo registró y situación del borrado de datos. Si no encuentras resultados, utiliza **Quitar filtros**.

## 5.3. Editar un equipo

1. Abre el equipo y pulsa **Editar datos**.
2. Corrige marca, modelo, serie, fecha de ingreso, ubicación u observaciones.
3. Pulsa **Guardar cambios**.
4. Verifica los datos en la ficha.

La condición y el destino cambian mediante las operaciones del responsable ambiental. La edición general tampoco ofrece modificar la categoría ni la campaña de origen; revísalas antes del alta.

Los equipos **Reasignados** o **Entregados a gestor** ya tienen un destino final documentado y no permiten editar datos. Comunica las inconsistencias al responsable o administrador.

## 5.4. Ver el historial de un equipo

1. Abre la ficha.
2. Desplázate a **Historial del equipo**.
3. Revisa los ingresos, diagnósticos, reparaciones y decisiones registrados.
4. Consulta fecha, descripción, responsable, cambio de estado y referencia de respaldo, cuando estén disponibles.
5. Pulsa **Imprimir ficha** si necesitas una copia. El navegador permite imprimir o guardar como PDF si ofrece esa opción.

El historial de movimientos no puede modificarse desde la interfaz. Permite seguir el recorrido documentado del equipo.
