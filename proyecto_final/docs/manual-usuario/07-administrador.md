# 7. Administrador

[Volver a portada e índice](../manual-usuario.md)

**Requisito:** iniciar sesión como administrador. Este perfil incluye las funciones del capturista y del responsable ambiental.

## 7.1. Gestionar usuarios y roles

### Crear una cuenta

1. Abre **Usuarios → Nuevo usuario**.
2. Captura **Nombre completo**, **Correo electrónico** y **Contraseña inicial**.
3. Selecciona **Capturista**, **Responsable ambiental** o **Administrador**.
4. Guarda y comprueba la cuenta en el listado.
5. Entrega las credenciales mediante el canal establecido por la institución.

El correo debe ser válido y único. La contraseña debe tener entre 8 y 72 caracteres, con letras y números. Las cuentas nuevas se crean activas.

### Editar, restablecer acceso o desactivar

1. Localiza la cuenta y pulsa **Editar**.
2. Actualiza nombre, correo o rol.
3. Para restablecer la contraseña, escribe una en **Nueva contraseña**; si dejas el campo vacío, conserva la actual.
4. Desmarca **Cuenta activa** para suspender el acceso o márcala para reactivarlo.
5. Guarda y comprueba el resultado.

La desactivación impide el acceso y se valida en las solicitudes de sesiones existentes. No puedes desactivar tu propia cuenta de administrador ni quitarte ese rol. Siempre debe existir al menos un administrador activo.

Las contraseñas anteriores no se muestran. No hay registro público de cuentas ni recuperación de contraseña por correo.

## 7.2. Gestionar catálogos: categorías y gestores

### Categorías

1. Abre **Categorías**.
2. Selecciona **Nueva categoría** o **Editar**.
3. Captura **Nombre**, **Tipo**, **Peso promedio (kg)** y **Valor de reposición (MXN)**.
4. Usa valores no negativos para peso e importe y añade una **Descripción** si corresponde.
5. Guarda y revisa el resultado.

El tipo determina reglas de manejo. El valor de reposición interviene en la clasificación de reparación y los cálculos económicos; el peso promedio se usa en las estimaciones ambientales. Revisa estos datos con el responsable antes de cambiarlos.

### Gestores

1. Abre **Gestores → Nuevo gestor**, o edita uno existente.
2. Captura **Nombre**, **Tipo de gestor**, **Contacto** y **Dirección**, según corresponda.
3. Guarda.
4. Después de revisar su documento de respaldo fuera del sistema, pulsa **Verificar**.
5. Escribe el **Número de autorización o documento** y confirma.

La verificación habilita al gestor para nuevas entregas. La plataforma documenta la revisión del administrador; no valida automáticamente el documento con una fuente externa.

Para retirar la habilitación, utiliza **Revocar verificación** y confirma con **Sí, revocar**. El responsable ambiental puede crear y editar gestores, pero únicamente el administrador verifica y revoca.

## 7.3. Configuración

La versión revisada no incluye una pantalla llamada **Configuración**. Las opciones disponibles se atienden en los siguientes lugares:

| Necesidad | Ubicación |
|---|---|
| Tamaño de letra y contraste | Controles de lectura; preferencia de cada navegador. |
| Permisos y acceso de cuentas | Usuarios. |
| Tipos, pesos y valores de referencia | Categorías. |
| Receptores y documentos de verificación | Gestores. |
| Datos y estado de campañas | Campañas. |

La dirección del sitio, la conexión al servidor y los parámetros de instalación corresponden al personal técnico y se describen en el README y la documentación técnica. No se cambian desde el panel administrativo.
