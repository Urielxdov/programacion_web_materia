# 10. Glosario

[Volver a portada e índice](../manual-usuario.md)

| Término | Significado en E-Waste 360° |
|---|---|
| Administrador | Perfil que gestiona cuentas, roles, categorías y verificación de gestores, además de las operaciones ambientales. |
| Borrado seguro de datos | Procedimiento realizado sobre el dispositivo para eliminar información. La plataforma registra la confirmación; no lo ejecuta. |
| Campaña | Actividad de recolección con fechas, lugar y tipos de equipo aceptados. |
| Capturista | Perfil que registra equipos y mantiene sus datos permitidos. |
| Categoría | Clasificación con tipo, peso promedio y valor de reposición utilizados por reglas e indicadores. |
| Condición | Situación técnica: pendiente de diagnóstico, funcional, reparable, reutilizable o gestión especializada. |
| Conservar como respaldo | Guardar un equipo disponible para uso posterior, indicando su ubicación. No es un destino final. |
| CSV | Archivo de valores separados por comas que permite consultar indicadores en una hoja de cálculo. |
| Destino | Situación de gestión: en inventario, en reparación, reasignado, conservado o entregado a gestor. Es distinto de la condición. |
| Diagnóstico | Registro de funcionamiento, daños, riesgos y costo estimado de reparación. |
| Equipos declarados | Cantidad que las personas planean llevar a una campaña. |
| Equipos recibidos | Registros del inventario asociados a una campaña. |
| Evidencia o respaldo | Referencia a un oficio, folio, manifiesto o comprobante que documenta un movimiento. |
| Folio | Identificador único asignado al equipo, por ejemplo `EW-2026-0047`. |
| Funcional | Equipo que enciende y funciona sin reparación necesaria ni riesgos que obliguen a gestión especializada. |
| Gestión especializada | Condición por riesgos, daño estructural grave, reparación no rentable o reparación fallida. Requiere entrega documentada a un gestor verificado. |
| Gestor verificado | Receptor cuya documentación fue revisada y registrada por el administrador para habilitar entregas en el sistema. |
| Historial | Secuencia de movimientos, fechas, responsables y referencias disponibles. No se modifica desde la interfaz. |
| Indicador | Dato calculado para conocer resultados, como recuperación, ahorro o residuo evitado. |
| Movimiento | Registro de ingreso, diagnóstico, envío o resultado de reparación, reasignación, conservación o entrega. |
| Participación | Registro público de una persona y de los equipos que planea llevar. |
| RAEE | Residuos de aparatos eléctricos y electrónicos. |
| Reasignación | Entrega documentada de un equipo funcional o reutilizable a un área o persona para darle otro uso. |
| Reparable | Equipo sin riesgos que obliguen a gestión especializada y con costo estimado de hasta el 50 % del valor de reposición de su categoría. |
| Residuo evitado | Estimación de masa de equipos recuperados, calculada con pesos promedio. |
| Responsable ambiental | Perfil que diagnostica, registra reparaciones y destinos y gestiona campañas y reportes. |
| Reutilizable | Condición obtenida después de una reparación exitosa; permite reasignar el equipo. |
| Rol | Conjunto de permisos asignado a una cuenta. |
| Sesión | Periodo de acceso autenticado, hasta cerrar sesión o su vencimiento. |
| Trazabilidad | Posibilidad de seguir el recorrido del equipo mediante su folio, operaciones y respaldos. |
| Valor de reposición | Importe de referencia de la categoría utilizado en reglas de reparación y cálculos económicos. |
