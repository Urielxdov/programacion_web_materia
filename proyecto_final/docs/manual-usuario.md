# E-Waste 360°

## Manual de usuario

**Plataforma para la gestión sustentable de residuos electrónicos y tecnológicos en una institución educativa**

| Dato | Información |
|---|---|
| Proyecto | E-Waste 360° |
| Asignatura | Programación Web y Desarrollo Sustentable |
| Periodo | Agosto–diciembre de 2026 |
| Versión del manual | 1.0 |

| Público | Visitantes, capturistas, responsables ambientales y administradores |
