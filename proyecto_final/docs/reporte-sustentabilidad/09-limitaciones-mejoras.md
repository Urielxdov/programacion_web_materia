# 9. Limitaciones y mejoras futuras

[Portada e índice](../reporte-sustentabilidad.md)

## Limitaciones identificadas

| Limitación | Consecuencia |
|---|---|
| No existe una línea base institucional medida | No se puede demostrar una reducción real respecto a un periodo anterior. |
| Peso y reposición son referencias por categoría | Masa y ahorro son estimaciones, no mediciones individuales. |
| “Recuperados” incluye reparación exitosa sin destino final | El criterio 12.6 no se cumple plenamente bajo una interpretación estricta. |
| No se confirma el proceso posterior a la entrega | No puede afirmarse reciclaje final ni porcentaje real de materiales recuperados. |
| Verificación de gestores manual | Depende de la revisión externa; no hay consulta automática ni control de vencimiento del permiso. |
| Evidencia capturada como texto | No se almacenan originales ni se valida autenticidad del comprobante. |
| Eventos de historial posteriores a algunas transacciones | Un fallo puede dejar operaciones sin movimiento correspondiente. |
| Historial sin sello criptográfico ni auditoría externa | No equivale a evidencia inalterable frente a acceso directo a la base. |
| Agregados por categoría con unión a reparaciones | Varias reparaciones exitosas de un mismo equipo podrían multiplicar ciertos conteos. |
| Ahorro de reparación se suma por evento | Reparaciones sucesivas pueden repetir beneficio; costos fallidos no se descuentan del ahorro mostrado. |
| Catálogo actual en parte de los cálculos | Cambiar pesos o valores puede modificar resultados históricos; el ahorro de reparación ya guardado conserva su importe. |
| Sin evaluación de ciclo de vida ni energía | No se cuantifica beneficio climático neto de mantener un equipo antiguo. |
| Sin medición de aprendizaje, salud o inclusión | Participación y accesibilidad implementada no prueban resultados sociales. |
| Sin auditoría completa de accesibilidad y privacidad | No se acredita conformidad integral por los controles existentes. |

## Mejoras priorizadas

1. **Precisión de resultados y evidencia.** Separar reparación, reasignación documentada y tratamiento comprobado. Preagrupar reparaciones por equipo y revisar ahorro acumulado para evitar duplicidades.
2. **Trazabilidad completa.** Incorporar originales de oficios y certificados, huellas de archivos, historial de autorizaciones y una cola transaccional o conciliación de eventos.
3. **Medición institucional.** Levantar línea base, registrar peso real y necesidad de reposición, asignar periodos y conservar valores históricos.
4. **Seguimiento del nuevo uso.** Documentar recepción, funcionamiento posterior, meses de servicio y salida de equipos conservados.
5. **Gestión normativa.** Añadir vencimientos, alcance del permiso, tipo de residuo, revisión periódica y campos que apoyen el plan institucional aplicable.
6. **Protección e inclusión.** Definir privacidad y retención y ejecutar pruebas de accesibilidad y uso con población diversa.
7. **Evaluación ampliada.** Incluir costos completos y, después de definir metodología y fuentes, estimaciones de ciclo de vida y emisiones.

Estas son propuestas; no deben presentarse como funciones ya disponibles. El reporte documenta el estado revisado sin modificar la lógica de negocio del sistema.
